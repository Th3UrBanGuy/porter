The Mechanism
How Porter works
No dashboards to babysit, no YAML to write. Your device talks to the Connector Portal, the portal brokers your Cloudflare identity, and Porter does the rest.
1

Install & run

One dynamic installer detects your platform — Linux, macOS, Termux or WSL — installs Python, cloudflared, dependencies and the porter CLI. A systemd/launchd service keeps it alive.

2

Link the Connector Portal

Sign in with your portal account (porter cf portal-login). The password is exchanged once for a scoped device API key and is never stored on the device.

3

Pick accounts · verified instantly

The portal lists every connected Cloudflare account. Choose one or many. Each pulled set is proven with a forced token refresh — you see VERIFIED or FAILED immediately.

4

Tunnel & self-heal

Create tunnels per subdomain from the dashboard or CLI. Expired tokens refresh automatically; if rotation broke them, Porter re-pulls from the portal before failing.

Why Porter
Built for headless reality
Raspberry Pis, VPS boxes, Termux phones, CI containers — anywhere a browser isn't guaranteed.
⚙

Multi-account

Store several Cloudflare accounts locally, switch the active one with a single command, forget devices cleanly. Each account is independently verified and tracked.

✓

Verified connections

Every linked account gets exactly one forced OAuth refresh against Cloudflare. Success or failure surfaces instantly — never silently. You know immediately if credentials are valid.

↻

Self-healing tokens

Refresh → re-pull fallback chain keeps tunnels breathing when tokens rotate elsewhere. If the local token is expired, Porter pulls fresh credentials from the portal automatically.

🔒

Password never stored

Portal passwords are exchanged once for a device API key using Argon2id hashing. Tokens sit AES-256-GCM encrypted on the portal — never on your device in plaintext.

⌨

Full CLI parity

Everything the web UI does lives under porter cf ... — scriptable, SSH-friendly, automatable. Create tunnels, manage accounts, check status, all from the terminal.

☁

One installer

Detects distro, package manager, CPU arch and service manager. Same file works on Debian, Fedora, Arch, macOS, Termux, and Windows (WSL). Handles python3-venv, cloudflared, and gunicorn setup.

📡

Short URLs

Generate compact shareable links for any tunnel. One click to shorten, one click to copy. Perfect for sharing access to your self-hosted services.

🚀

Real-time progress

Watch each tunnel creation step live with Server-Sent Events. DNS cleanup, tunnel setup, hostname config, DNS record creation — all streamed in real time.

💻

Self-hosted

Run on your own VPS with full control over your data. No external services required except Cloudflare. Your tokens, your server, your rules.
