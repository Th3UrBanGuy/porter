1. Overview

Cloudflare Tunnel Portal is a self-hosted web application that exposes local services to the internet through Cloudflare Tunnels. Cross-platform: Linux, macOS, Windows, and Termux. Just enter a port and subdomain, and the system handles everything else automatically.

Key Features

  • Cross-Platform - Linux, macOS, Windows, Termux. One installer, one command.
  • OAuth 2.1 Authentication - One-click Cloudflare authorization, no API tokens to manage
  • MCP Integration - All API calls go through Cloudflare's Model Context Protocol server
  • GUI Command - porter gui opens the dashboard in your browser instantly
  • Real-Time Progress - SSE-powered step-by-step progress during tunnel creation
  • Auto Port Detection - Scans your system for running services (cross-platform)
  • Passcode Protected - SHA-256 hashed passcode secures the portal
  • Clean Dashboard - Copy URLs, stop tunnels, monitor everything

2. Architecture

Step Details

  1. DNS Cleanup - Checks for existing DNS records and removes conflicts
  2. Tunnel Setup - Creates or reuses a Cloudflare tunnel
  3. Hostname Configuration - Adds subdomain to tunnel ingress rules
  4. DNS Record - Creates CNAME: subdomain.domain -> tunnel_id.cfargotunnel.com
  5. Start cloudflared - Retrieves tunnel token and spawns process

5. First-Time Setup

One-Line Install (Recommended)

# Linux, macOS, Windows (Git Bash/WSL), Termux
# Linux, macOS, Termux
curl -fsSL https://raw.githubusercontent.com/Th3UrBanGuy/porter/self-hosted/install.sh | bash

# Windows PowerShell / WSL
irm https://raw.githubusercontent.com/Th3UrBanGuy/porter/self-hosted/install.sh -OutFile install.sh; bash install.sh

The installer auto-detects your platform, installs Python, pip, cloudflared, and all dependencies.

Installer flags

--dir PATH       install location   (default ~/porter)
--port N         dashboard port     (default 7262)
--passcode PASS  pre-set passcode
--service        register systemd/launchd autostart
--no-start       don't launch after install
--branch NAME    source branch      (default self-hosted)
--uninstall      remove Porter + services

Manual Install

# 1. Install dependencies
pip install -r requirements.txt

# 2. Ensure cloudflared is installed
which cloudflared || {
  curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 \
    -o /usr/local/bin/cloudflared
  chmod +x /usr/local/bin/cloudflared
}

# 3. Install CLI
pip install -e .

# 4. Start and open dashboard
porter gui
The OAuth flow uses dynamic client registration - no pre-registered app needed.

6. Creating Tunnels

8. API Reference

Port Scanning

GET /api/ports/scan
# Response: { "open_ports": [4000, 7262, 8080] }

Create Tunnel (SSE)

POST /api/tunnel/create/stream
Content-Type: application/json
{ "subdomain": "myapp", "port": 8080 }
# Response: text/event-stream with step-by-step progress

Stop Tunnel

POST /api/tunnel/stop/{key}
# Response: { "success": true, "message": "Tunnel stopped" }

Best Practices

  • Restrict portal access with firewall rules
  • Use HTTPS reverse proxy for the portal
  • Choose a strong passcode
  • Monitor portal.log for unauthorized access

12. CLI (Porter Command)

Porter includes a cross-platform CLI for managing everything from the terminal. Works on Linux, macOS, Windows, and Termux.

Install CLI

cd porter
pip install -e .

# Verify installation
porter --help

Commands

CommandDescription
porter guiOpen the web dashboard in your browser
porter platformShow platform info (OS, arch, available tools)
porter server start|stop|restart|statusManage the server process
porter server logs --followTail logs in real time
porter cf connectConnect Cloudflare account (OAuth from terminal)
porter cf statusCheck Cloudflare connection
porter cf portal-login [url]Link a portal account (blank URL = primary portal)
porter cf connectionsList portal accounts (+ locally stored ones)
porter cf use <id>Switch active account (offline fallback to local)
porter cf syncRe-pull + verify the active account
porter cf accountsShow local accounts with verify badges
porter cf forget <prefix>Remove an account from this device
porter tunnelsList active tunnels
porter tunnel create <sub> <port>Create a tunnel
porter tunnel stop <sub>Stop a tunnel
porter portsList listening ports
porter keys create <name>Create API key
porter setupSetup wizard

Examples

# Open dashboard
porter gui

# Connect Cloudflare from terminal
porter cf connect

# Create a tunnel
porter tunnel create panel 7262

# Check platform info
porter platform

# List listening ports
porter ports

# Create an API key
porter keys create my-script

# Watch logs
porter server logs --follow

13. API Keys

API keys allow programmatic access without using the passcode directly.

Authentication

Pass API keys via the X-API-Key header:

curl -H "X-API-Key: pk_..." http://localhost:7262/api/tunnels

Endpoints

MethodEndpointDescription
GET/api/keysList all API keys
POST/api/keysCreate API key
DELETE/api/keys/<id>Delete API key
POST/api/keys/<id>/rotateRotate API key

Create via API

curl -X POST http://localhost:7262/api/keys \
  -H "Content-Type: application/json" \
  -H "X-Passcode: your_passcode" \
  -d '{"name": "my-script"}'

14. FAQ

Can I use this with any Cloudflare plan?

Yes. Free, Pro, Business, and Enterprise all work.

What happens if I restart my VPS?

Tunnels stop. Recreate them through the portal or CLI.

Why OAuth instead of API tokens?

No token management, automatic rotation, scoped access.

Does it work on Windows?

Yes. Git Bash, WSL, and MSYS2 are supported. Native Windows uses PowerShell commands.

Does it work on Android?

Yes. Termux is fully supported with auto-installed cloudflared.

How do I open the dashboard?

Run porter gui from the terminal. It opens the dashboard in your default browser.
