Powerful CLI

Every feature at your fingertips. Cross-platform, zero config.

GUI

porter gui
Open the web dashboard in your browser

Server

porter server start|stop|restart|status
Manage the Porter server process

Cloudflare

porter cf connect|status|disconnect
OAuth flow from the terminal

Tunnels

porter tunnel create <sub> <port>
Expose localhost to the internet

API Keys

porter keys create|delete|list
Manage programmatic access keys

Platform

porter platform
Show OS, arch, available tools
# Quick start
$ porter gui                          # Open dashboard
$ porter cf connect                   # Connect Cloudflare
$ porter tunnel create panel 7262     # panel.domain -> localhost:7262
$ porter keys create github-action    # Create CI/CD key
$ porter server logs --follow         # Watch logs

Architecture

Clean, minimal, secure. No database, no external dependencies.

No Database

Flat JSON files. config.json, tunnels.json, tokens.json. Easy to backup, edit, version control.

Single Process

One cloudflared process per tunnel. Auto-detects and adopts existing processes on restart.

MCP Integration

All Cloudflare API calls go through their MCP server. No manual token management.

Install in Seconds

One command. Everything handled automatically.

# Linux, macOS, WSL, Termux
$ curl -fsSL https://tinyurl.com/2ctqvyfp | bash

# Windows PowerShell (two-step, most reliable)
$ curl.exe -fsSL https://tinyurl.com/2ctqvyfp -o install.sh
$ bash install.sh

# With custom port and passcode
$ PORTER_PORT=8080 PORTER_PASSCODE=123456 curl -fsSL https://tinyurl.com/2ctqvyfp | bash

# Manual install
$ git clone https://github.com/Th3UrBanGuy/porter.git
$ cd porter && pip install -r requirements.txt && pip install -e .
$ porter gui
~30s
